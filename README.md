# DFS-BFS
Artificial Intelligence Techniques Lab
Question: The task is to check if we can reach from any random start grid to the mentioned target
grid by moving the Blank space ('B').
In one step, the Blank space can move either top or down or left or right.
Input: Generate a random grid of 3x3 shape containing numbers from 1 to 8 and a blank space.
A sample grid is as follows: -
3 2 1
4 5 6
8 7 B
The target grid is fixed.
1 2 3
4 5 6
7 8 B
1. Compare Breadth First Search (BFS) and Depth First Search (DFS) with respect to the number
of steps required to reach the solution if they are reachable.
2. Comment on which algorithm will be faster and when, by mentioning proper intuition and
examples.
